Importer un joueur

Import en 3 étapes
  1. Une seule fois : glisse le bouton ci-dessous dans ta barre de favoris (Ctrl+Maj+B pour l'afficher).
  2. Ouvre le profil du joueur sur tracker.gg (bouton « Récupérer les stats » ou « Ouvrir tracker.gg »).
  3. Sur cette page, clique sur le favori ⇪ Envoyer à NodeCG : le joueur apparaît ici automatiquement.
